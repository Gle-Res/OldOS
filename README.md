# OldOS

一款还原经典旧版 iOS 界面风格的主题与体验项目。

## 简介

OldOS 是一个把现代 iOS 设备界面还原成经典旧版 iOS 风格的项目，从图标、字体、动画到系统应用的交互逻辑，都尽可能复刻当年的视觉与体验。适合怀旧用户、UI 研究者和喜欢经典拟物化设计的人使用。

## 功能

- 还原经典旧版 iOS 主屏布局与图标风格
- 复刻系统应用的界面与交互
- 支持锁屏、控制中心、通知中心等界面
- 内置经典壁纸与音效
- 适配多种设备尺寸，持续更新

## 使用

1. 下载并安装 OldOS
2. 打开应用，按引导完成初始化
3. 在主屏浏览经典界面
4. 进入设置可调整主题、壁纸等选项
5. 遇到问题可在 Issues 中反馈
